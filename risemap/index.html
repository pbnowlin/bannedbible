About these numbers — please read

Counts vary by source and method. There is no single official registry of mosques or Hindu temples in the U.S., so totals differ depending on what a source counts — for example, only incorporated nonprofits, only purpose-built buildings, or also prayer spaces inside other buildings. RiseMap does not merge sources into one “true” total; each view uses one source consistently so states can be compared fairly.

Mosque view: HIFLD (Homeland Infrastructure Foundation-Level Data) All Places of Worship dataset, IRS 501(c)(3) snapshot, July 2024 — 2,058 mosques nationally. Because it is built from IRS nonprofit records, informal or unregistered prayer spaces are not counted.

Hindu temple view: HinduTemples.net directory — 534 temples nationally (530 across the 50 states + DC; the remainder are in U.S. territories, which are not shown on this map).

Per-capita rates use 2024 U.S. Census Bureau state population estimates: rate = count ÷ population × 100,000. Population is a state's total population, not its Muslim or Hindu population, so the rate shows how present these houses of worship are in the wider community.

Names & cities: the full name-and-city directory for each state is still being imported and verified, so this page shows verified state totals only rather than an incomplete list. You can browse the underlying directories at HIFLD GeoPlatform (mosques) and HinduTemples.net (temples).
