About these numbers — please read

Counts vary by source and method. There is no single official registry of mosques in the U.S., so totals differ depending on what a source counts — for example, only incorporated nonprofits, only purpose-built buildings, or also prayer spaces inside other buildings. Counts are now aggregated from the best sources for each state, deduplicated by name and city where possible, rather than taken from one single source for every state. That makes the low-count states in particular more accurate — several single-source zeros were wrong — but it also means cross-state comparison is less exact, because different states may lean on different sources. Click any state to see the individual sources behind that state's number.

Mosques & Islamic centers: mosques and Islamic centers are counted together as one category — a place counts whether it is called a mosque or an Islamic center, deduplicated by name and city. Aggregated total 2,080 nationally. Sources used per state include HIFLD (Homeland Infrastructure Foundation-Level Data) All Places of Worship, IRS 501(c)(3) snapshot, July 2024; the ISPU 2020 U.S. Mosque Survey; ASARB / the 2020 U.S. Religion Census; POI directory data (2025); and mosquesusa.com. HIFLD alone is built from IRS nonprofit records, so informal or unregistered prayer spaces — and places that never filed separately — are missed by that source, which is why the other sources are now combined for the states that were rechecked.

* = uncertain — a verified floor, an unnamed source-only count, a possible additional place, or a congregation without a purpose-built building; see the state's source note. Click a corrected state and its panel lists each source's count for that state and explains the asterisk where one appears.

Per-capita rates use 2024 U.S. Census Bureau state population estimates: rate = count ÷ population × 100,000. Population is a state's total population, not its Muslim population, so the rate shows how present mosques are in the wider community.

Names & cities: the full name-and-city directory for each state is still being imported and verified, so this page shows verified state totals only rather than an incomplete list. You can browse the underlying directory at HIFLD GeoPlatform.
