About these numbers — please read

Counts vary by source and method. There is no single official registry of mosques or Hindu temples in the U.S., so totals differ depending on what a source counts — for example, only incorporated nonprofits, only purpose-built buildings, or also prayer spaces inside other buildings. Counts are now aggregated from the best sources for each state, deduplicated by name and city where possible, rather than taken from one single source for every state. That makes the low-count states in particular more accurate — several single-source zeros were wrong — but it also means cross-state comparison is less exact, because different states may lean on different sources. Click any state to see the individual sources behind that state's number.

Mosque view: aggregated total 2,079 mosques nationally. Sources used per state include HIFLD (Homeland Infrastructure Foundation-Level Data) All Places of Worship, IRS 501(c)(3) snapshot, July 2024; the ISPU 2020 U.S. Mosque Survey; ASARB / the 2020 U.S. Religion Census; POI directory data (2025); and mosquesusa.com. HIFLD alone is built from IRS nonprofit records, so informal or unregistered prayer spaces — and places that never filed separately — are missed by that source, which is why the other sources are now combined for the states that were rechecked.

Hindu temple view: aggregated total 744 temples nationally (740 across the 50 states + DC; the remainder are in U.S. territories, which are not shown on this map). The temple counts now include verified satsang centers, ashrams, and Hindu community/cultural centers with regular worship, from a November 2026 recount that added 171 such places (national total 573 → 744; 740 across the 50 states + DC). Counts remain aggregated from the best sources for each state. Sources used per state include the HinduTemples.net directory, the HUA directory, the 2020 U.S. Religion Census, and individually named temples and congregations found in the recheck of low-count states and the November 2026 recount. “Probable” in a state’s panel means existence as a congregation is directory-verified but the current weekly schedule was not individually re-confirmed.

* = uncertain — a verified floor, an unnamed source-only count, a possible additional place, or a congregation without a purpose-built temple; see the state's source note. Click a corrected state and its panel lists each source's count for that state and explains the asterisk where one appears.

Per-capita rates use 2024 U.S. Census Bureau state population estimates: rate = count ÷ population × 100,000. Population is a state's total population, not its Muslim or Hindu population, so the rate shows how present these houses of worship are in the wider community.

Names & cities: the full name-and-city directory for each state is still being imported and verified, so this page shows verified state totals only rather than an incomplete list. You can browse the underlying directories at HIFLD GeoPlatform (mosques) and HinduTemples.net (temples).

RiseMap is a reference tool to help people find established Muslim and Hindu communities when relocating, travelling, or researching an area. Figures are a snapshot from the sources and dates named above — check the source directory before relying on a count for a specific place. By 'temple' we mean a Hindu place of worship — including mandirs, satsang centers, ashrams, and Hindu community or cultural centers with regular worship — not only purpose-built temple buildings.
