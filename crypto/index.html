Crypto

What this is

Encrypt a block of text with a password, and decrypt it again with the same password. Everything happens inside this browser tab — nothing is sent anywhere and nothing is saved. Close the tab and nothing is left behind.

The result is plain text, so it travels through anything that carries text: email, chat, a note in a file, paper.

To encrypt

  • Leave the switch set to Encrypt.
  • Type or paste your text into Message. Up to 1 MiB.
  • Enter a password, then type it again to confirm.
  • Press Encrypt, then Copy to take the result.

Send the encrypted block to the other person, and give them the password separately — a different app, or in person. Sending both together defeats the point.

To decrypt

  • Set the switch to Decrypt.
  • Paste the whole block into Encrypted message, including the BEGIN and END lines.
  • Enter the password and press Decrypt.

If it will not open, the password is wrong or the block was altered or cut short on its way to you. Ask the sender to copy it again.

Your password

  • Twelve characters minimum. Longer is better — a password manager's generator is the easiest way to get a good one.
  • Anyone who has the password can read the message, so pass it along carefully.
  • Keep it somewhere safe before you close this tab. There is no recovery and no reset. If the password is lost the message cannot be opened again, by you or by anyone.

The other buttons

Clear empties every field on the page, and Copy puts the output on your clipboard. Switching between Encrypt and Decrypt also clears both boxes, so copy anything you want to keep before you switch.

This browser does not expose the Web Crypto API on this page, so nothing here can run. Web Crypto requires a secure context — open this page over HTTPS.
